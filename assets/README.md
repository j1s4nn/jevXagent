# Assets Directory

This directory contains visual assets for the jevXagent repository.

## Files

### banner.svg
Main banner for README.md and GitHub repository. Shows:
- jevXagent logo and version
- Performance statistics (3× faster, 80% token savings, 75% cost reduction)
- Gradient background with circuit patterns

### architecture.svg
Complete system architecture diagram showing:
- Request flow from user to agent
- Line J injection point
- Jev decision engine
- Performance metrics overlay

### line-j-flow.svg
Side-by-side comparison diagram:
- **Left:** Traditional agent (slow, 2,400ms, 240 tokens)
- **Right:** With jevXagent (fast, 890ms, 48 tokens)
- Highlights the Line J injection step

## Using These Assets

### In README.md
```markdown
![jevXagent Banner](assets/banner.svg)
![Architecture](assets/architecture.svg)
![Line J Flow](assets/line-j-flow.svg)
```

### In Documentation
Link to these SVG files directly from any markdown document in the repository.
